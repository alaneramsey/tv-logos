# tv-logos

Channel logos for a home Plex Live TV setup, each centred on a 720x300 (2.4:1) transparent canvas so the
Plex smart-TV apps, which stretch logos to fill that shape, show them undistorted.

Generated by the IPTV Engine in alaneramsey/tv-media-stack. Logos are the property of their owners; most come
from [tv-logo/tv-logos](https://github.com/tv-logo/tv-logos).
